# Guess the Number 猜數字遊戲

A simple browser guessing game built with vanilla HTML, CSS and JavaScript — no frameworks, no build tools, just open it and play.

🔗 **Play it live:** https://burcehsu.github.io/guess-the-number/

## How it works

The game picks a random number between 1 and 100. You enter a guess, and it tells you whether your guess is too high, too low, or correct — tracking how many attempts it took.

## Tech stack

Plain HTML / CSS / JavaScript. No dependencies, no installation required.

## Run it locally

1. Clone this repo:
   ```
   git clone https://github.com/BurceHsu/guess-the-number.git
   ```
2. Open `index.html` in your browser. That's it.

## Project structure

```
guess-the-number/
├── index.html   # page structure
├── style.css    # styling
└── script.js    # game logic
```
